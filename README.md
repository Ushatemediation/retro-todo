# To-Do List — rétro desktop

Список задач в стиле ранних Macintosh: монохромный рабочий стол, пиксельные иконки, окна с полосатым заголовком. Чистый HTML, CSS и JavaScript без сборки и зависимостей.

## Что делает
- Добавляет задачу по Enter или кнопке Add; пустую строку не принимает.
- Помечает задачу выполненной и возвращает её в работу.
- Удаляет отдельную задачу и все выполненные сразу.
- Хранит задачи в localStorage браузера.

## Как запустить
Откройте `index.html` в браузере. Сервер не требуется.
